## 快速开始

### 系统要求

- Obsidian 1.0.0 或更高版本
- S3 兼容存储服务账号
- 网络连接

### 安装插件

1. 下载插件文件
2. 放入 `.obsidian/plugins/obsidian-sync-plugin/` 目录
3. 重启 Obsidian
4. 在设置中启用插件

### 首次配置

1. 打开设置 → 同步插件
2. 填写 S3 存储配置
3. 设置同步密码（请牢记！）
4. 设置设备名称
5. 点击「测试连接」验证配置
6. 点击「立即同步」开始同步

## 配置指南

### S3 存储配置

#### Cloudflare R2（推荐）

1. 登录 Cloudflare Dashboard
2. 创建 R2 存储桶
3. 创建 API 令牌
4. 填写配置：

| 字段 | 值 |
|------|-----|
| 服务端点 | `https://<account-id>.r2.cloudflarestorage.com` |
| 存储桶 | 你的存储桶名称 |
| 区域 | `auto` |
| 访问密钥 | API 令牌的 Access Key ID |
| 访问密钥密码 | API 令牌的 Secret Access Key |

#### AWS S3

1. 创建 S3 存储桶
2. 创建 IAM 用户
3. 配置权限策略
4. 填写配置：

| 字段 | 值 |
|------|-----|
| 服务端点 | `https://s3.<region>.amazonaws.com` |
| 存储桶 | 存储桶名称 |
| 区域 | `us-east-1` 等 |
| 访问密钥 | IAM 用户 Access Key |
| 访问密钥密码 | IAM 用户 Secret Key |

### 同步密码

**重要**：同步密码用于加密所有数据，请务必：

- 使用强密码（12 位以上，包含大小写字母、数字、符号）
- 妥善保管，不要丢失
- 所有设备使用相同密码

### 自动同步

| 选项 | 说明 |
|------|------|
| 自动同步 | 启用后自动定时同步 |
| 同步间隔 | 同步间隔时间（秒） |

推荐设置：
- 桌面端：300 秒（5 分钟）
- 移动端：600 秒（10 分钟）

## 日常使用

### 手动同步

- 点击状态栏的同步图标
- 使用命令面板：`Ctrl/Cmd + P` → `立即同步`

### 查看同步状态

- 状态栏图标显示当前状态
  - ✅ 空闲
  - 🔄 同步中
  - ❌ 错误
  - ⏸️ 暂停

- 使用命令：`显示同步状态`

### 处理冲突

当两台设备同时修改同一文件时：

1. 插件自动创建冲突副本
2. 冲突副本命名：`原文件名 (冲突 2026-06-10T14-30-00).md`
3. 手动合并内容
4. 删除冲突副本

## 高级功能

### 选择性同步

通过规则控制哪些文件参与同步：

1. 打开设置 → 同步规则
2. 添加包含/排除规则
3. 规则支持 Glob 模式

**规则示例**：

| 模式 | 说明 |
|------|------|
| `notes/**` | 同步 notes 文件夹下所有文件 |
| `**/*.md` | 同步所有 Markdown 文件 |
| `attachments/**` | 排除 attachments 文件夹 |
| `**/*.tmp` | 排除所有 .tmp 文件 |

### 版本历史

查看和恢复文件历史版本：

1. 右键点击文件
2. 选择「查看版本历史」
3. 选择要恢复的版本
4. 点击「恢复」

### 同步规则导入导出

导出配置便于多设备配置：

1. 设置 → 高级 → 导出配置
2. 复制配置字符串
3. 在其他设备导入

## 故障排除

### 常见问题

#### 同步失败：连接错误

**原因**：网络问题或 S3 配置错误

**解决**：
1. 检查网络连接
2. 验证 S3 端点地址
3. 检查访问密钥是否正确

#### 同步失败：解密失败

**原因**：同步密码不正确

**解决**：
1. 确认使用相同的同步密码
2. 如果忘记密码，需要清空远端数据重新同步

#### 文件没有同步

**原因**：可能被同步规则排除

**解决**：
1. 检查同步规则设置
2. 确认文件路径不在排除规则中

#### 冲突频繁发生

**原因**：多设备同时编辑

**解决**：
1. 减少同时编辑同一文件
2. 提高自动同步频率
3. 同步后再编辑

### 日志查看

1. 使用命令：`显示同步日志`
2. 查看详细操作记录
3. 导出日志用于排查问题

### 重置插件

如果遇到严重问题：

1. 关闭同步插件
2. 删除 `.obsidian/plugins/obsidian-sync-plugin/` 目录
3. 重新安装插件
4. 重新配置

## 最佳实践

### 安全建议

1. ✅ 使用强同步密码
2. ✅ 定期备份重要数据
3. ✅ 使用 HTTPS 端点
4. ❌ 不要在公共场所同步
5. ❌ 不要分享同步密码

### 性能优化

1. 排除不需要同步的大文件
2. 使用合适的同步间隔
3. 移动端启用 WiFi 下同步

### 团队协作

本插件设计为个人使用，如需团队协作：

1. 每人使用独立的设备名
2. 避免同时编辑同一文件
3. 及时解决冲突
