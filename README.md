# Obsidian 同步插件

跨设备端到端加密同步插件，支持在不同电脑和手机之间同步 Obsidian 笔记仓库。

## 特性

- 🔒 **端到端加密** - 所有数据在上传前加密，密码仅存本地
- 🌐 **S3 兼容存储** - 支持 AWS S3、Cloudflare R2、MinIO 等
- 📱 **跨平台** - 桌面端和移动端使用同一套代码
- 🔄 **离线支持** - 离线编辑，联网后自动同步
- ⚡ **大文件支持** - 自动分块上传大文件
- 🔁 **冲突处理** - 自动检测冲突并创建副本

## 安装

### 手动安装

1. 下载 `main.js`、`manifest.json`、`styles.css`
2. 复制到 `.obsidian/plugins/obsidian-sync-plugin/` 目录
3. 重启 Obsidian
4. 在设置中启用插件

### 开发安装

```bash
# 克隆仓库
git clone <repo-url>
cd obsidian-sync-plugin

# 安装依赖
npm install

# 开发模式（热重载）
npm run dev

# 构建
npm run build

# 测试
npm test
```

## 配置

### 1. S3 存储配置

| 配置项 | 说明 | 示例 |
|--------|------|------|
| 服务端点 | S3 兼容存储地址 | `https://s3.amazonaws.com` |
| 存储桶 | Bucket 名称 | `my-obsidian-sync` |
| 区域 | S3 区域 | `us-east-1` 或 `auto` |
| 访问密钥 | Access Key ID | `AKIAIOSFODNN7EXAMPLE` |
| 访问密钥密码 | Secret Access Key | `wJalrXUtnFEMI...` |

#### 推荐存储服务

| 服务 | 免费额度 | 特点 |
|------|----------|------|
| [Cloudflare R2](https://www.cloudflare.com/products/r2/) | 10GB/月 | 无出口费，推荐 |
| [AWS S3](https://aws.amazon.com/s3/) | 5GB/12个月 | 稳定可靠 |
| [MinIO](https://min.io/) | 自托管 | 完全控制 |

### 2. 同步配置

| 配置项 | 说明 |
|--------|------|
| 同步密码 | 用于加密的密码，**请务必记住** |
| 设备名称 | 当前设备的名称，便于识别 |
| 自动同步 | 是否启用自动同步 |
| 同步间隔 | 自动同步间隔（秒） |

## 使用方法

### 首次同步

1. 打开设置 → 同步插件
2. 填写 S3 存储配置
3. 设置同步密码
4. 设置设备名称
5. 点击「测试连接」验证配置
6. 点击「立即同步」开始同步

### 添加新设备

1. 在新设备上安装插件
2. 使用**相同的 S3 配置和同步密码**
3. 设置不同的设备名称
4. 点击「立即同步」

> ⚠️ **重要**：同步密码必须与首次创建仓库时一致，否则无法解密数据。

### 手动同步

- 点击状态栏的同步图标
- 或使用命令面板：`Ctrl/Cmd + P` → `立即同步`

## 工作原理

### 同步流程

```
┌─────────────────────────────────────────────────────────────┐
│                        同步流程                              │
├─────────────────────────────────────────────────────────────┤
│  1. 扫描本地变更                                             │
│     ├─ 检测新建文件                                         │
│     ├─ 检测修改文件（比较 mtime）                           │
│     └─ 检测删除文件                                         │
│                                                             │
│  2. 上传变更                                                │
│     ├─ 加密文件路径                                         │
│     ├─ 加密文件内容                                         │
│     └─ 上传到 S3                                            │
│                                                             │
│  3. 拉取远端变更                                            │
│     ├─ 列出远端对象                                         │
│     ├─ 下载新/修改文件                                      │
│     └─ 解密并验证哈希                                       │
│                                                             │
│  4. 应用变更                                                │
│     ├─ 创建新文件                                           │
│     ├─ 更新修改文件                                         │
│     └─ 处理冲突                                             │
│                                                             │
│  5. 更新索引和状态                                          │
└─────────────────────────────────────────────────────────────┘
```

### 加密方案

| 项目 | 算法 | 说明 |
|------|------|------|
| 密钥派生 | PBKDF2-SHA256 | 200,000 次迭代 |
| 内容加密 | AES-256-GCM | 每次随机 IV |
| 路径加密 | AES-256-GCM | 分段加密 |
| 完整性校验 | SHA-256 | 内容哈希 |

### 冲突处理

当两台设备同时修改同一文件时：

1. 本地版本保留不变
2. 远端版本保存为冲突副本
3. 冲突副本命名格式：`原文件名 (冲突 2026-06-10T13-30-00).md`

## 忽略规则

以下文件/目录默认不同步：

- `.obsidian/` - Obsidian 配置目录
- `.` 开头的隐藏文件
- `.trash/` - 回收站
- `.sync-*` - 插件自身文件

## 故障排除

### 同步失败：连接错误

- 检查网络连接
- 验证 S3 端点地址
- 检查防火墙设置

### 同步失败：访问被拒绝

- 验证 Access Key 和 Secret Key
- 检查 Bucket 权限策略

### 同步失败：解密失败

- 确认同步密码正确
- 确认使用相同的仓库 ID

### 找不到远端文件

- 检查 Bucket 名称
- 确认首次同步已完成

## 安全注意事项

1. **同步密码**：请使用强密码并妥善保管，丢失将无法恢复数据
2. **S3 凭据**：建议使用最小权限的 IAM 策略
3. **网络**：使用 HTTPS 端点确保传输安全
4. **备份**：首次使用前建议备份重要数据
